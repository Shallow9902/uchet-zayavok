# Учёт заявок

Веб-приложение для создания заявок и отслеживания их статуса. Поддерживает установку на главный экран iPhone и работу без интернета после первой загрузки.

## Установка на iPhone

Откройте сайт в Safari, нажмите «Поделиться» → «На экран Домой» → «Добавить».

## Хранение данных

Данные сохраняются в браузере на текущем устройстве. Синхронизации между устройствами и резервного копирования нет. Очистка данных сайта может привести к потере заявок.

Авторизация выполняется в браузере, пароли хранятся в открытом виде. Не используйте личные или повторяющиеся пароли.
